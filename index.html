Daily structure for the job search

Standing rules — apply in every phase
  • Same anchor times every day (wake, exercise, main block) even as content inside them changes.
  • Split "job search" into sub-tasks — outreach, applications, research, admin — rather than one undifferentiated block.
  • Exercise/rehab is non-negotiable — medical, not optional fitness.
  • Protect the social block deliberately — it disappears first if left unscheduled.
